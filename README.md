# Rune Simulator

Made by furyfoxIII.

A client-side, offline calculator for a rune-opening incremental game.
Predict how long it'll take (and how much it'll cost) to get X copies of a
rune, and plan your currency spending — all in the browser, no server
needed.

## Running it

Just open `index.html` in a browser. There's no build step and no server —
everything is plain HTML/CSS/JS loaded via `<script>` tags.
